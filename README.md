# maryamghodrat.com

Author website for Maryam Ghodrat, hosted on GitHub Pages.

- English pages are at the top level; the Farsi version of each page is in `fa/` with the same file name.
- When you change a page, make the same change to its Farsi twin.
- Styles: `css/style.css` (colours are at the top).
- `404.html` is shown for any missing address.
